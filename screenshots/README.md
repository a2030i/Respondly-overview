# Screenshots

ضع لقطات شاشة المنتج هنا بهذه الأسماء بالضبط ليظهرها README تلقائياً:

| الملف | المحتوى المقترح |
|---|---|
| `inbox.png` | اللقطة الرئيسية — صندوق الوارد الموحّد (820px عرض على الأقل) |
| `dashboard.png` | لوحة التحكم والتحليلات |
| `ai-reply.png` | الردود المقترحة بالذكاء الاصطناعي |
| `campaigns.png` | بناء الحملات |
| `crm.png` | ملف العميل / CRM |

**نصائح للعرض على المستثمرين:**
- استخدم صوراً بدقة عالية (Retina) بعرض ≥ 1600px ثم تُصغّر تلقائياً.
- أخفِ أرقام العملاء الحقيقية في اللقطات (خصوصية + احترافية).
- يكفي PNG. لو الملف كبير، اضغطه عبر tinypng.com.

بعد إضافة الصور: `git add screenshots && git commit -m "add screenshots" && git push`
